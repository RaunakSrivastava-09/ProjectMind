# ProjectMind

> **What if you could talk to your project?**

ProjectMind is an AI-powered voice project assistant that converts natural-language voice commands into real project actions.

Instead of navigating through multiple screens to create tasks, report snags, search project information, or check project status, users can simply speak to ProjectMind.

---

## 🚀 Features

- 🎙️ Voice command input
- 🗣️ Speech-to-text using the browser Web Speech API
- 🤖 AI-powered intent understanding using Groq
- 🧩 Entity extraction from natural language
- ✅ Confirmation before important actions
- 📋 Create project tasks using voice
- 🚧 Create project snags using voice
- 🔎 Search tasks and snags using natural language
- 📊 Get project status using voice
- 💾 MongoDB persistence
- 🔊 Spoken AI responses
- 🇮🇳 English/Indian English and Hindi speech recognition support
